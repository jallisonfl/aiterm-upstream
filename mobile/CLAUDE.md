# aiterm-mobile

Native Android companion for the aiterm desktop (`projects/aiterm`, branch `5lime`). Kotlin + Jetpack Compose, three screens: pair (scan QR), sessions, one session as a conversation with an input bar. It is a client of the desktop's remote API (`src-tauri/src/remote.rs` — plain HTTP + WebSocket, bearer token from the QR); the phone never sees terminal bytes. Package `com.fivelime.aiterm`, min SDK 26, target 37.

- Build: `JAVA_HOME=/usr/lib/jvm/java-21 ANDROID_HOME=~/Android/Sdk ./gradlew assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`
- Install: `adb install -r app/build/outputs/apk/debug/app-debug.apk`
- Pair without a QR (dev): `adb shell am start -a android.intent.action.VIEW -d "aiterm://pair?v=1&p=8877&t=<token>&f=<cert sha256 hex>&n=<name>&h=<lan ip>&h=<public ip>"` — token in `~/.local/share/aiterm/remote.json`, fingerprint = `openssl x509 -in ~/.local/share/aiterm/remote-cert.pem -outform DER | sha256sum`.
- Transport: HTTPS to the desktop's self-signed cert, pinned by that fingerprint (Pinning.kt); every `h=` is remembered and tried in order (LAN first, public last). The desktop maps its own port via UPnP, so this works from cellular with nothing in between.
- Transport gotcha: Android 16+ local network protection silently drops app packets to RFC1918 addresses unless the manifest declares `ACCESS_LOCAL_NETWORK` (we do now) and the user grants "Local network" in app settings — the exact symptom is "works on cellular, dead on home Wi‑Fi". Probes run in parallel and prefer LAN over public (no hairpin needed); a network switch (Wi‑Fi ↔ cellular) triggers an immediate re-probe; the candidate list refreshes from `/v1/status` `hosts` on every connect so a DHCP move can't strand the phone.
- Conversation transport: the spine (`docs/architecture/spine.md`), not the old 3 s `/v1/sessions/{id}/conversation` poll — `GET /v1/sessions/{id}/spine?after=N` once on open, then `{"type":"spine"}` WebSocket frames into `ConversationStore` (Spine.kt, unit-tested in SpineTest.kt). Seq gap or a new epoch → refetch; a working session silent for 20 s → refetch; a desktop with no spine route (404) falls back to the old poll, mapped onto the same rows.
- Status: v0.2 — pinned TLS, works off-network; brand icons (assets/icons, from the desktop's set); dashboard strip (usage, search, Recent/Project); working / needs-you / on-desktop / running states from the desktop terminal; Stop button = interrupt (Esc); markdown (headings/links/quotes/etc) + summarized tool cards; conversation ends with a "Files from this session" strip (ledger-backed: image thumbnails + file pills, tap for full view) and paths mentioned in a turn are tappable chips. Home: search + filter chips (engine/has-files/active), hamburger drawer (usage details, Refresh, Settings, Forget). Settings: three themes (state-backed palette in Theme.kt) + display time zone.
